HearthWebsite translation

Uses your saved desktop translation engine. This tab stays clickable while visible text is translated.

Language codes: en, ar, ru, zh, ja. Use auto only if the selected translation engine supports it.
Pair this extension in Hearth

In Hearth → Integrations, paste this origin under Translate websites and save browser access. Start the server, then copy its current address and API token into this popup.

The token is stored on this browser profile. The current website never receives it.
