# Hearth mascot icon

Two friendly speech-bubble characters carry **A** and **ع**, representing English
and Arabic conversation. Ivory and turquoise figures sit on indigo. The icon is
shared by cloud and offline variants; the Android adaptive foreground includes
extra mask padding. The previous fire concept is not used.

The generated source artwork is `app/src/main/res/drawable-nodpi/hearth_mascot.png`.
It was created with the image-generation tool on 2026-09-13 and refined for smooth
edges. No claim is made that the tool used a selectable Astra image model.

When replacing the mark, keep faces and language glyphs readable at launcher size,
check circular and squircle masks, and retain the adaptive safe padding. This
mascot does not imply sign-language support or guaranteed translation accuracy.
