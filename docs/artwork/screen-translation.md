# Screen translation artwork

Created 2026-10-23 with the built-in image generation tool for the owner-requested
Screen translation chooser. It is decorative; the actual mode selection, language
controls and permissions remain native accessible UI.

Project assets:

- `app/src/main/res/drawable-nodpi/screen_translation_hero.png`
- `desktopApp/src/desktopMain/resources/screen-translation-hero.png`

Both retain the generated transparent PNG. No external runtime image host is used.

Final prompt:

> Use case: stylized-concept. Asset type: a polished raster illustration for the Screen translation chooser in Hearth Android, small banner artwork also usable on desktop. Primary request: depict translating visible text across apps, with one floating browser page and one small manga page, linked by a subtle translation arrow, plus a cursor passing freely through a translucent translation panel. Style: elegant friendly editorial 3D paper illustration, simple forms, refined soft shadows, restrained turquoise and lavender accents that fit a dark charcoal app and also a light app. Browser page has abstract text lines; manga page has two original simple speech bubbles and abstract monochrome art. Composition: balanced wide horizontal silhouette, generous transparent padding, all subjects fully contained, legible at 320dp wide by 150dp high. Transparent background, no baked text, no labels, no letters, no numbers, no brands, no watermarks, no full app screenshot. Avoid clutter and photorealistic faces.
