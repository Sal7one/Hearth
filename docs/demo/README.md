# Hearth conversation demo

[Watch/download the 23.7-second vertical preview](hearth-conversation-preview.mp4).
[Optional caption file](hearth-conversation-preview.en.srt).

1080 × 1920, 30 fps, H.264/AAC, MP4 with fast-start metadata. The audio track is
silent; essential information is visible throughout. This is a conversation
feature preview, not a microphone or streaming-ASR benchmark.

## What is real

The footage comes from Hearth 0.8.2 on a Samsung SM-S908E running Android 16.
The sample was **typed** in English and translated on-device by the installed
ML Kit English/Arabic packs. Nemotron appears in the selected pipeline label but
ASR is not invoked by typed input. Original and translated text are the app's
actual output. The Face to face screen and its rotated upper half are real UI.
Idle time was trimmed and the final frame held for reading; no result or caption
was fabricated. No latency, quality or universal language-support claim is made.

No personal conversation, API key, microphone recording or system notification
content is shown. Only the generated station-directions sample was removed from
history after recording, and the original history preference was restored.
The final card uses the Arabic/English mascot artwork in [brand notes](../brand/README.md).
