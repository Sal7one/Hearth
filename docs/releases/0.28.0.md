# Hearth 0.28.0

**Galaxy S25 Ultra / S22 Ultra: choose Play ARM64 below. You only need one APK to install Hearth.**

> **Draft / QA test build.** These are test-signed QA APKs, version **0.28.0 / code 94**,
> for Android 9+. The desktop work in this branch is separate (PR #4); Windows is parked
> and not claimed. Model weights are never bundled.

## What is new in this APK

- **Experimental local Ming-3.0 TTS on Android**, off by default behind a Voice settings
  switch. It uses the pinned arm64 JNI and a separately downloaded or imported ~850 MB
  bundle (English/Chinese, 44.1 kHz, one-shot, about 1 GB RAM). The model is not inside
  the APK.
- The Ming panel reports the real JNI load/runtime reason, the missing-component count,
  download/import actions, and the honest one-shot/300-character limits.
- Existing Vosk, Whisper, translation and hosted/self-hosted voice paths are unchanged.
  The new desktop **ports** (Moonshine variants, OmniVoice, Magpie, Chatterbox) are
  documented in PR #4; their Android native adapters were already part of the app and
  are still packaged, but this draft makes no new desktop-engine claim for the APK.

## Ming local TTS — read before enabling

- Off by default; enable it in **Settings → Read captions aloud → Voices & read aloud →
  Local → Ming-3.0 TTS 0.5B · experimental**.
- The bundle is about 850 MB and needs ~1.7 GB free while downloading/installing.
- It is one-shot: the whole utterance is generated before playback. There is no native
  streaming or mid-synthesis cancellation.
- English and Chinese only. On the test SM-G781B (8 GB) the measured path was about
  RTF 2.1 with the dotprod build/4 threads and ~1.02–1.28 GB peak; scalar is much slower.
- Human listening/quality, FOSS-on-device import, and live-caption read-aloud remain
  owner checks.

New optional native families mostly require ARM64; an APK supporting a processor does not
make every engine available on it. **Magpie, MOSS, OmniVoice, Oute, Chatterbox and Ming are
ARM64-only**; the x86/ARMv7 APKs no longer contain their unusable JNI wrappers. Supertonic
and the shared speech stack remain available on the other ABIs.

## Verification

- `./gradlew test :app:compilePlayQaKotlin :app:compileFossQaKotlin` — pass.
- `./gradlew :app:assemblePlayQa :app:assembleFossQa` — pass; all ten QA APKs.
- `python3 scripts/verify-release.py` — pass for signatures, package/version, ABI/ELF,
  16 KB alignment, permissions, native set, and pinned Ming DSO hashes.
- Real Android Ming on SM-G781B: in-APK `System.loadLibrary`/JNI under SELinux and
  **88,200 frames** in the 0.28.0 debug `MingLocalDeviceTest`.
- Earlier 0.27.3 owner-UI run: four AudioTrack syntheses (English + Chinese), 1.28 GB
  peak, persistence and flag-off gating (see `docs/ming-android-ui.md`).
- No new transcript or quality claim is made for unchanged engines.
