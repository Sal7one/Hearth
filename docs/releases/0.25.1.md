# Hearth 0.25.1 · Searchable model explorer

> **Archived draft notes.** Use the [current installation guide](../installing-qa.md) for downloads.

The explorer now makes it easier to find a compatible model and see where its
files came from. Basic mode keeps the existing bundle workflow. Advanced mode
keeps custom imports, independent speech/translation/voice choices and engine
controls.

This build includes the expanded models, portable setups, DataStore preferences
and optional GPU engines documented for [0.25.0](0.25.0.md).

- Search model families, native/English/Arabic/Chinese language names, aliases,
  formats and precision using multiple words. Installed filters apply to the
  same precision shown on the card; reset actions explain empty results.
- Open original model cards, pinned artifact pages and licenses from each
  catalog. Readable file pages do not unexpectedly start large downloads. FOSS
  exposes selectable source addresses without delegating network operations.
- Publisher installation badges require a trusted receipt bound to the archive
  and verified manifest, or the pinned single-model bytes. A compatible custom
  profile alone cannot claim an installed catalog model. Damaged packages show
  actual errors while healthy explicitly selected packages remain usable.
- OCR and voice model file/queue work runs on IO dispatchers. Voice search uses
  positive, checked language inventories instead of prose that can contain
  exclusions. GPU choices and native inference behavior remain unchanged.

The repeatable link audit exports the actual Kotlin installer catalog before
checking pinned publisher revisions, sizes, hashes and source URLs. It never
downloads model weights. See the dated model explorer audit report for the
complete inventory, evidence levels and rate-limit handling:
[135 files and 119 source links](../model-catalog-audit-2026-10-19.md).

## Corrected draft APKs

The original unsigned Release uploads could not be installed on Android. They
have been replaced with ten **signed, release-optimized QA APKs**, Play/FOSS
across ARM64, ARMv7, x86, x86_64 and universal. Version code: **85**.

The original ARM64 APK for Galaxy S25 Ultra or S22 Ultra was
`hearth-0.25.1-play-qa-arm64-v8a.apk`. The universal APK included all four
architectures for TVs or devices with an unknown CPU. FOSS was the offline flavor.

These use the same `com.sal7one.transiber.qa` package and signing certificate as
the published 0.23.10 QA builds, so those installations can update in place,
retaining app-private models and settings. Keep the existing app installed.
QA uses the existing debug certificate and is not a production-signed release.

The [source tag](https://github.com/Sal7one/Hearth/tree/v0.25.1) identifies
the corrected draft's application code. Its original distribution included
`INSTALLING.md` and `SHA256SUMS`. Device testing remained with the owner.

## Validation

- Full Gradle `test`, both QA Kotlin compilations and Play/FOSS QA/Release
  assembly passed. Each QA test report contains 588 tests with no failures;
  Play skips two platform cases and FOSS skips nine unavailable network cases.
- All ten QA APKs passed `apksigner` verification, manifest identity/version,
  ABI/ELF, pinned runtime, 16 KB alignment and permission checks. The signing
  certificate was compared with the actual published 0.23.10 Play ARM64 APK.
  Earlier checks of unsigned Release files covered internal packaging only;
  those files were not installable and are no longer offered in this draft.
- Eleven offline audit-verdict/HTTPS tests passed. Live inventory checks passed
  for all 135 downloadable files and 119 source URLs; the report distinguishes
  128 full size/hash matches from seven Vosk size-only remote checks.
- The unchanged speech host suite passed all 307 ASan/UBSan checks with Clang.
  CI now selects Clang explicitly for that suite, matching the Android toolchain.
- Staged-source and full-history secret scans passed. Owner device testing and
  production signing remain separate from these host/package checks.
