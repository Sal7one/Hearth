# Hearth 0.27.1

> **Archived release notes.** The assets listed below are historical. Use the [current installation guide](../installing-qa.md) for downloads.

## Historical APKs

| Your device / preference | Original APK | Size |
| --- | --- | ---: |
| **S25 Ultra, S22 Ultra and most modern phones** | **Play ARM64 APK** | 115.9 MB |
| Modern phone, strictly offline edition | FOSS ARM64 APK | 107.8 MB |
| Android TV or unknown processor | Play universal APK | 203.8 MB |

Play supports explicit cloud connections and in-app model downloads. FOSS has no network permission; import model files yourself. TVs use cloud connections or separately installed Android system voices; downloaded local models are blocked.

These are optimized, signed **QA test builds**, version 0.27.1 / code 91, for Android 9+. Model weights are separate. [Installation and update guide](../installing-qa.md).

## What's new

- Simpler **Speech → Translation → Voice** settings, with everyday bundles first and advanced controls tucked away.
- Searchable models and grouped downloads; imports install without changing your active pipeline. Preferences and portable JSON setups remain supported.
- Fifteen model-family integrations, compact Jisr translation and reusable Arabic/English article-speech libraries.

Both precisions belong to the same model family. Advanced settings expose the publisher's 14 Arabic dialect tags, including Saudi. The complete local test/build gates and APK/AAR verification passed. All six app configurations report 674 tests each with no failures or errors. GitHub native host checks passed. Model-by-model evidence and known errors are retained in the evidence ZIP and [validation record](https://github.com/Sal7one/Hearth/blob/v0.27.1/docs/handoff/validation.md).

The new STT families are Cohere Arabic, Fun-ASR MLT Nano, Voxtral Realtime, Audar Flash and OWSM. Translation adds QuickMT, SMaLL-100, EuroLLM, Riva-Translate and Jisr. Optional voice adapters cover Magpie, OmniVoice, MOSS Nano, Chatterbox Multilingual V3 and OuteTTS 1.0. CPU support is built; optional Vulkan covers the first three STT families, and GGUF translation retains CPU/Vulkan/Adreno OpenCL choices. GPU performance still needs device testing.

OWSM's Arabic smoke output was inaccurate, Voxtral reprocesses a bounded audio window, and Oute's desktop CPU synthesis was slower than real time. Riva's publisher-template line breaks are corrected, but translation mistakes remain. Chatterbox includes the verified graph conversion and mandatory Perth watermarking. [Translation evidence](https://github.com/Sal7one/Hearth/blob/v0.27.1/docs/models/mt-expansion-host-smoke-2026-10-20.md).

This release-page reorganization bundles supporting files without changing APKs, AARs, model ZIPs, source snapshot, signed tag or version. Every original file is preserved directly or inside a bundle; the provenance file records its location and digest.

</details>

**Testing status:** new local families remain experimental. S25/S22 speed, memory, heat and listening quality still need owner testing. Ming-3.0 is an optional hosted CUDA-server integration; it has no local Android runtime or published Arabic coverage, and no real CUDA checkpoint inference has been validated here.
