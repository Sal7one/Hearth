# Hearth 0.27.3

**Galaxy S25 Ultra / S22 Ultra: choose Play ARM64 below. You only need one APK to install Hearth.**

## Install the app

| Your device / preference | Download | Size |
| --- | --- | ---: |
| **S25 Ultra, S22 Ultra and most modern phones** | **[Play ARM64 APK](https://github.com/Sal7one/Hearth/releases/download/v0.27.3/hearth-0.27.3-play-qa-arm64-v8a.apk)** | 115.9 MB |
| Modern phone, strictly offline edition | [FOSS ARM64 APK](https://github.com/Sal7one/Hearth/releases/download/v0.27.3/hearth-0.27.3-foss-qa-arm64-v8a.apk) | 107.8 MB |
| Android TV or unknown processor | [Play universal APK](https://github.com/Sal7one/Hearth/releases/download/v0.27.3/hearth-0.27.3-play-qa-universal.apk) | 203.8 MB |

Play supports explicit cloud connections and in-app model downloads. FOSS has no network permission; import model files yourself. TVs use cloud connections or separately installed Android system voices; downloaded local models are blocked.

These are optimized, signed **QA test builds**, version 0.27.3 / code 93, for Android 9+. Model weights are separate. [Installation and update instructions](https://github.com/Sal7one/Hearth/releases/download/v0.27.3/INSTALLING.md).

## Settings and navigation

- Back returns directly to the existing bottom sheet at its previous scroll position, keeping expanded inline options without replaying the entrance animation.
- Nested model/download pages unwind before returning to the sheet. Explicit Home, tab changes and external links keep their normal behavior.
- Caption, conversation, typed-translation and camera settings also reopen after visiting their model/voice pages. Overlay controls and screen-reading setup return to their original sheet.
- Saved-state restoration waits for actual settings data before laying out the sheet, preventing a short loading view from resetting its position.

Model runtimes and model packages retain the verified 0.27.1 baseline. Test packaging and SDK cancellation coverage are corrected for CI; no new model-performance result is claimed.

**Distribution:** this is the official GitHub release. Installable artifacts retain the existing test-signed QA package and certificate for in-place updates; production signing is separate.

**Testing status:** new local families remain experimental. S25/S22 speed, memory, heat and listening quality still need owner testing. Ming-3.0 is an optional hosted CUDA-server integration; it has no local Android runtime or published Arabic coverage, and no real CUDA checkpoint inference has been validated here.
