# Hearth 0.22.3 — cloud translation and pipeline reliability

**An experimental, offline-first Android captioning and translation app.** Read live
captions over other apps, translate camera images and manga, type across languages,
and use Conversation or Face to face with read aloud. Hearth remains a **test / proof
of concept**, with English, Arabic and Simplified Chinese interfaces.

## What changed since 0.22.1

- **Cloud captions use the chosen translation route.** Switching or reselecting
  OpenAI/Soniox streaming in the simple screen selects integrated cloud translation,
  instead of accidentally retaining a local Hy-MT override. Explicit connection
  changes restart the stream correctly.
- **Each feature keeps its translator choice.** Camera and screen/manga reading share
  one choice; Conversation, Face to face and typed text share another. Their pickers
  no longer overwrite the live-caption translator. **Use everywhere** remains the
  explicit way to apply a selection across Hearth.
- **Overlay switching waits for model cleanup.** Moving between audio captions and
  screen reading shows progress while the previous models finish releasing, with a
  bounded timeout and messages in all three app languages.
- **Clear really retires typed work.** Blank input, invalid setup and same-language
  input release the previous model reservation. A cancelled model load cannot start
  obsolete inference or restore old text.
- **Streaming failures retain their cause.** Retired sockets ignore late callbacks,
  stop accepting audio and finish shutdown safely; genuine provider errors are
  preserved rather than replaced by a generic rejected-send message.
- **Read aloud reports one completion outcome.** Failures are preserved and invalid
  remote voice choices do not allocate a client.

**If an old OpenAI setup still shows Hy-MT:** stop captions, open **Speech &
translation**, and reselect **Cloud / OpenAI**. Confirm **Translator · OpenAI · cloud
translation**, choose your destination language, then start again. A deliberately
selected separate translator remains supported.

Existing installations without a feature-specific local choice keep the previous
main-model fallback until a choice is made in that feature's picker.

## Validation and current limits

- All six app test variants: **309 cases each, zero failures/errors**; existing
  platform-specific skips remain. Common JNI: **75 cases per variant**, no failures.
- Both APK flavors pass native dependency, pinned artifact, 16 KiB alignment and
  network-permission checks. Native common, speech, OCR, voice and Vosk host suites
  pass, including sanitizer coverage for independent handles during cancellation.
- Samsung SM-S908E / Android 16 checks verified saved model selection across app
  restarts and the intended sharing within feature groups. No paid cloud request or
  model-quality benchmark was part of that configuration check.

This update does not claim every model/language pair is device-tested. Live model
handoffs under load still need broader device testing. Local accuracy, speed and
memory needs vary; large simultaneous models may not fit on smaller phones.
No production JNI ABI or vendored model runtime was changed in this release.
