# Hearth 0.25.2 · Honor translation-only captions

**Galaxy S25 Ultra / S22 Ultra:** choose
**`hearth-0.25.2-play-qa-arm64-v8a.apk`** from the draft assets. For a TV or
unknown CPU architecture, choose `hearth-0.25.2-play-qa-universal.apk`. FOSS is
the offline flavor.

These are signed, release-optimized QA APKs, package
`com.sal7one.transiber.qa`, version 0.25.2/code **86**. They use the same signing
certificate as the published 0.23.10 QA and corrected 0.25.1 draft, so keep the
existing installation and update in place. They are not production-signed APKs.
This draft contains no unsigned APKs.

## Fixed behavior

Selecting **Translation only** previously showed original captions whenever a
translation had not arrived. That fallback existed in phone captions, TV
subtitles and held-history copying. Translation only now hides source text in
all three paths, including pending, empty and unavailable translations.

The phone shows a neutral waiting message until translated text is available.
TV subtitles retain the last completed translation while the next source
utterance waits. Actual engine/provider and history errors remain visible.

Engines that return translated text directly retain that output: each caption
now carries explicit source/target/intermediate provenance. An English pivot is
kept out of the requested target display until the second translation stage
finishes. Streaming translation-only partials are also displayed when their
source partial is empty.

Original/Both choices still show their selected content. Switching back to
captions-only mode shows the source captions while preserving the saved
translation display preference. Display filtering does not change raw engine
text, final IDs, deduplication, queue bounds, saved-history routing, TTS or the
independent model/provider stages. Native runtimes are unchanged.

The draft includes signed QA APKs for both flavors and all four CPUs plus
universal APKs, a source-only archive, portable setup examples, installation
instructions and SHA256SUMS. Device testing remains with the owner.
