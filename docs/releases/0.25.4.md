# Hearth 0.25.4 · Optional captions while translating

**Galaxy S25 Ultra / S22 Ultra:** choose
**`hearth-0.25.4-play-qa-arm64-v8a.apk`**. For a TV or unknown CPU architecture,
choose `hearth-0.25.4-play-qa-universal.apk`. FOSS is the offline flavor.

These are signed, release-optimized QA APKs, package
`com.sal7one.transiber.qa`, version 0.25.4/code **88**. The signing certificate
matches published 0.23.10 QA and the corrected 0.25.1/0.25.3 drafts, so update
the existing installation in place. They are debug-signed test artifacts, not
production-signed APKs. This draft includes no unsigned APKs.

## New choice

In phone overlay settings, open **CC & translation → Translation only** and
enable **Show original while translating**. On TV, open overlay controls →
**Text → Translation only** for the same switch. Labels and help are available
in English, Arabic and Chinese.

The switch is off by default and saved in DataStore across launches and
orientation changes. When enabled, available original captions appear until
that line has translated text, which replaces the original automatically.
Phone, TV, held history and copying honor the same choice. Hiding partials
still hides interim text. Translation errors remain visible.

When disabled, Translation only keeps source captions hidden and TV retains
the last translated subtitle while the next utterance waits. Original/Both
and captions-only mode retain their existing behavior. Direct engine
translations remain visible; intermediate English is never mislabeled as
original text or the final target language. Providers with independent source
and translation runs retain their own IDs without guessing alignment.

Changing the switch updates presentation without restarting engines. Speech,
optional translation and optional TTS remain independent. No native runtime,
model selection, inference queue or provider credential handling changed.

The draft includes ten signed QA APKs, a source-only archive, portable JSON
setup examples, the model-source audit, installation instructions and
SHA256SUMS. Device testing remains with the owner.

## Model-family research

The [searchable offline report](../research/model-families-2026-10-19.html) and
[structured evidence](../research/model-families-2026-10-19.json) cover 124 entries:
35 STT models (32 counted families plus three related derivatives), 48 translation
checkpoints (38 named projects and 30 broader lineages), and 41 TTS families/model
lines. Quants and individual voices do not count as extra models. Shared ancestry
and older families remain explicit.

Each entry records parameter-count evidence, exact selected component bytes,
download scope, licenses, release evidence, language coverage, runtime proposals
and current Hearth support. File sizes are not RAM or uniform complete Android
install sizes. Nine translation checkpoints expose public metadata but require
publisher access approval for their weights. No weights were downloaded for
this survey and no new model is claimed integrated by the research alone.

AuroraASR-1M was published October 18: its INT8 weights are 1,056,232 bytes,
and its seven-file inference folder is 1,317,737 bytes before installed runtime.
It is English-only and requires a new validated adapter. sanoTTS heart-nano has
345,232 bytes of neural weights plus metadata, phonemizer and runtime. Tiny
footprints do not establish parity with larger models or Android speed.
