# Hearth 0.23.10 · TV dashboard and remote setup

Android TV now opens to large **Start Hearth** and **Stop Hearth** buttons over a
TV-style background. Setup lives behind **Speech setup**, with Speech, Language
and Voice tabs, independently scrolling options and a fixed Done button. Finished
setup no longer leaves three onboarding cards on the dashboard.

## Overlay and remote control

- The editor keeps a large cinematic preview visible beside category navigation
  and scrolling controls. Preview captions are samples, not captured speech.
- New/reset landscape layouts on TV and phones use **80% width / 30% height**;
  portrait stays **85% / 40%**. Both start at the bottom. Saved custom geometry
  takes priority, and the existing 144–320 dp default-height bounds still apply.
- Open **Hearth controls** from the TV launcher to hide/show or edit the overlay.
  The separate **Stop Hearth** launcher provides an emergency stop and closes
  Hearth. The dashboard's Stop button ends both caption and reading sessions
  while keeping the dashboard open. No remote shortcut buttons are required.
- Speech/provider failures preserve the saved overlay position.

## Phone setup and mobile compatibility

Play's TV setup uses OpenAI for speech, translation and optional read-aloud. Scan
the QR code with an iPhone or Android phone on the same private Wi-Fi, paste the
key on the phone, then approve the proposed settings on the TV. The transfer is
encrypted; credentials are not placed in the QR code or URL. The short-lived
listener closes on exit or after five minutes. Guest-network/client isolation or
router firewalls may block direct phone-to-TV access; the paired Google TV phone
keyboard is an alternative on supported TVs. Bluetooth key transfer is not added.

FOSS retains offline model import and device voices, with no network permissions.
All full settings and other providers remain under **Full interface**. Phone home
and Classic tabs remain available in portrait and landscape. Artwork is bundled
locally in both flavors; see [image prompts](../tv-artwork.md).

## Validation and limits

The required Gradle test/QA Kotlin gates, both QA builds and the APK verifier run
before publication. The APK verifier checks all ten APKs, native provenance and
integrity, dependency closure, ABI identity, 16 KB alignment, permissions and the
bundled phone crypto hash. Native common, speech, OCR, Vosk and voice host suites,
voice-server tests and package/ABI tests also pass for this release. The native
host suites use the installed LLVM 22.1.8 compiler on macOS; the older Apple
sanitizer runtime stalled during initialization. No native source or binary was
changed. The Gradle reports contain 3,018 cases across six app variants and two
common JNI variants, with zero failures/errors (27 flavor-specific skips).

Disposable Android 14 TV and Android 16 phone emulators exercise welcome/saved
setup, light/dark themes, Arabic RTL, full-interface switching and phone portrait/
landscape layouts. Screenshot fixtures use a fake credential and sample captions,
with no provider requests or live audio. These checks do not establish paid
provider quality or firmware-specific audio-capture behavior. Earlier remote and
placement testing on the owner's Android 14 TCL is documented separately.
