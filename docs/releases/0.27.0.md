# Hearth 0.27.0 · Simpler settings and complete model pipelines

Owner-testing **GitHub draft**. Galaxy S25 Ultra and S22 Ultra use the Play QA
ARM64 APK. The build is release-optimized, debug-signed QA, version 0.27.0 / code 90,
package `com.sal7one.transiber.qa`. It uses the existing QA certificate. TVs use
explicit cloud connections or their separately installed Android system voices;
downloaded local models are blocked. FOSS remains offline and supports imports.

## Settings and model library

- Settings opens with three pipeline cards: speech recognition, optional
  translation and optional voice output. Each has direct access to its choices.
- Basic mode keeps bundles and everyday controls prominent. Engine details,
  precision, paths, sources and file actions sit behind explicit disclosures.
- Model search and filters persist in DataStore. Installed models and repair
  actions are easier to find; unavailable alternatives stay out of the default
  translator chooser.
- Downloads group a model's components into one card with aggregate progress,
  pause/resume/retry/install actions and file details on demand. This includes
  two-file Audar and the voice families.
- Importing installs a package. Using it is a separate explicit action; imports
  no longer switch caption mode or replace the active speech model.
- Portable JSON setups, independent stage choices, imported source paths and
  launch validation remain supported. Caption translator edits keep their scope;
  changing all feature defaults is an Advanced action.

The existing option to show original captions while translation is pending remains
available. Typed translation, camera OCR and standalone article speech retain their
own input paths.

## Model roadmap integrations

| Stage | Families integrated | Execution |
| --- | --- | --- |
| Speech recognition | Cohere Arabic, Fun-ASR MLT Nano, Voxtral Realtime, Audar Flash, OWSM | ARM64 CPU; optional Vulkan for the first three |
| Translation | QuickMT, SMaLL-100, EuroLLM 1.7B Instruct, Riva-Translate 4B v2, Jisr 50M | CT2 CPU for compact models; existing CPU/Vulkan/Adreno OpenCL paths for GGUF |
| New voices | Magpie, OmniVoice, MOSS Nano, Chatterbox Multilingual V3, OuteTTS 1.0 | Separate optional ARM64 CPU adapters |

These are actual runtime/package integrations, with pinned sources, components,
licenses, model cards and real host inference evidence. They remain experimental
until owner phone and listening comparisons establish suitable defaults. Precision
variants are grouped together and do not count as additional trained families.

Jisr INT8 needs approximately 55 MB per direction, including tokenizer and notices;
FP32 needs approximately 198 MB. Advanced settings expose all 14 publisher dialect
tags, including Saudi. The faithful conversion preserves its trained decoder-start
embedding and full vocabulary. FP32 matched 21/21 reference examples; INT8 matched
15/21 FP32 outputs. Runtime ZIPs are importable; original safetensors cannot run
directly. [Jisr files, recipe and limitations](../models/jisr.md).

OWSM's Arabic smoke output was inaccurate. Voxtral's current partial-results port
reprocesses a bounded audio window. Oute's measured desktop CPU synthesis was much
slower than real time. These findings are recorded rather than promoted into speed
or quality claims. [Speech evidence](../models/stt-modern-cpu.md),
[voice SDK guide](../tts-sdk.md).

Riva's native prompt now uses the real line breaks produced by its pinned
publisher template. The previous literal `\n` separators were incorrect; one
retained English→Arabic fixture that echoed English now produces Arabic. The
corrected runtime passed both six-sentence directions plus active cancellation
and recovery checks. EuroLLM and QuickMT Arabic→English also ran on exact verified
weights. Translation mistakes remain in the saved outputs; these checks establish
functional integration, not a general quality or phone-speed gain.
[Exact translation evidence](../models/mt-expansion-host-smoke-2026-10-20.md).

Chatterbox uses an exact pinned graph conversion that removes omitted optional
input slots, plus a verified Perth checkpoint converter that never interprets
Python pickle. Mandatory watermarking occurs before PCM delivery. Source and
derived files have separate hashes, and publication remains atomic.

## Reusable Arabic and English speech library

The model-free `hearth-tts` core supplies bounded article streaming, cancellation,
voice matching and independent adapters. Supertonic's native code is now extracted
from the broad speech JNI module. A shared `hearth-onnx-runtime` AAR supplies the
single ONNX runtime used by Supertonic, MOSS and Chatterbox.

Supertonic supplies verified M1–M5 and F1–F5 male/female voices. Other families
retain unknown gender unless verified; design cues do not establish speaker
identity. OmniVoice and Oute carry noncommercial model restrictions. Adapter
licenses and downloaded model licenses are separate. No weights, credentials or
automatic downloads are included in the SDK. [Consumer guide](../tts-sdk.md).

## Ming-3.0 and device checks

All five Ming checkpoints retain sourced cards and explicit hosted integrations.
They are CUDA server options, have no published Arabic coverage, and have not
received real CUDA inference checks here. They are not Android GPU models.

Owner S25/S22 testing remains: Arabic/Gulf recognition, article pronunciation,
warm latency, memory, heat, sustained GPU behavior, stop/restart and UI usability.
No owner device or adb was used. Host checks do not establish phone performance.

## Validation

The full Gradle gate passes: all six app configurations report 674 tests each,
with no failures or errors. Both QA builds pass signature, package/version,
native hash/ABI/16 KB alignment and permission checks. All eight SDK release
AARs pass distribution checks, with no model weights or app code included.

Final gate results, artifact checksums, native source provenance, model conversion
inventories and SDK artifacts accompany the draft. See the
[validation record](../handoff/validation.md) for executed checks and the remaining
