## App gallery — Hearth 0.22.1

Captured from Hearth 0.22.1 (version code 43), cloud-capable QA build, on Samsung
SM-S908E running Android 16 on 2026-09-21. Ink theme, Dark appearance, default 100%
font scale, English interface. All nine PNGs are unedited 1440 × 3088 device
screenshots. README previews link to the full-resolution originals.

- **Home** shows the illustrated service carousel and Easy setup entry.
- **Easy setup** shows the local/cloud chooser, before any download or key entry.
- **Live captions** shows a ready local Nemotron configuration, before capture.
  This screenshot does not demonstrate microphone recognition or caption latency.
- **Conversation / Face to face** show the existing synthetic station-directions
  example entered through Type instead. These layouts share the same stored turn;
  the text was not regenerated by the currently selected model for these photos.
- **Type to translate** shows a fresh on-device Hy-MT2 1.8B Q4_K_M translation:
  “Where is the nearest train station?” → “أين أقرب محطة قطار؟”. Playback controls
  are visible; no audio playback claim is made.
- **Camera & OCR** shows an imported synthetic English text image recognized by
  PaddleOCR, then translated into Arabic by local Hy-MT2 1.8B Q4_K_M. The displayed
  OCR duration is one operation, not end-to-end translation latency or a benchmark.
- **Screen & manga** shows reading-overlay setup with Japanese Meiki and English
  translation selected. No screen-capture session is demonstrated by this image.
- **Settings** shows separate Local and Cloud tabs and model/feature setup cards.
  Cloud connection entries belong to the cloud-capable flavor.

Only synthetic example text is shown. No key fields, personal conversation history,
camera surroundings or notification text are published. Temporary typed input and
OCR capture state were cleared; prior model/language selections were restored and
existing keys/history retained. No paid API request was made. The separate
[video preview](../demo/README.md) records the older 0.8.2 UI.
